## Question

D15: How are Loci created and filled, given no extensions, archetypes or compositions?

## Options

_(none)_

## Final answer

Owner design: the kernel gives each Locus a makeChild() that creates a basic Locus linked both ways (child knows parent, parent knows child). The root is the only entry point (const Calculator = Locus.root(...), then Calculator.locus.makeChild()). The app fills each child with its own capabilities, dependencies and Rules inside the app, not in the Telos library. No compositions from packages, no extensions, no archetypes, no appliesTo. Archetype-like helpers (for example newCliApp()) may return later and are out of scope for M1. Cost accepted: a second app would duplicate interface code until it is extracted later.
